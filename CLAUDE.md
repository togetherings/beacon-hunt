# Notes for working on this repository

- `game/` is the BeaconHunt game for Kolibri Games (github.com/togetherings/kolibri-games). It uses
  the plugin's `photo-guess` service; the server keeps the answers, the page only shows photos.
- `beacon_pack/` is the pack tool (standard library only). Never commit a Mapillary token or a
  photo pack: the token comes from `MAPILLARY_TOKEN`, and photos are CC BY-SA, not MIT.
- The photo-pack format is shared with Kolibri Games (its docs/PHOTO_PACKS.md and photos.py):
  change both together. `beacon_pack/jpeg.py` is a copy of the plugin's metadata stripping
  (a test checks they match).
- `game/map/` is generated by `tools/import_singe_map.py` from SINGE's map. Don't edit it by hand.
- The region list is in `beacon_pack/regions.py` and in `game/game.js` (REGIONS); a test checks
  they match.
- The game and the pack tool share one version: `beacon_pack/__init__.py` and
  `game/kolibri-game.json`. Add a CHANGELOG entry before a release. Releases are published by a
  person in GitHub's Releases page (tag `vX.Y.Z`); the Release workflow attaches the game zip.
- Tests: `python -m pytest`; `python -m tests.e2e_browser` (needs kolibri-games, Playwright, Pillow).
- Keep the game light: it runs on old phones and laptops, served by a Raspberry Pi.
- Writing style for anything users see: plain words, sentence case, active voice.
